## Follow-up — Exp08 Master/Core Overload Repair

This follow-up preserves the original fanout STOP and the later Exp08 STOP above. The user approved repair of the Exp08 overload-target and Master-source defects only, followed by continuation until the next new mandatory defect.

### Defect reviewed

The reviewed defects were: Exp08 injected DC-SoC at fixed node 0, did not select one existing Master/Core overload target, and applied the cluster-head overload factor to every DC-SoC cluster-head destination.

### Master representation

The faithful current abstraction is a deterministic core-rooted structural DAG. Its effective Master is the unique active node satisfying:

```text
dcsoc_role == "core"
dcsoc_parent is None
```

`ahbn.topology.get_dcsoc_master` now implements this rule and fails explicitly if the completed structure has anything other than one active root. It does not invent or mutate a new role layer.

### Eligible overload-set construction

After `assign_dcsoc_clusters` completes, the Exp08 DC-SoC path builds the eligible set from every active existing `dcsoc_role == "core"` node. The unique root/Master is already a member of that core set. Leaf/tail nodes are excluded by construction.

### Seeded overload selection

The completed structure is passed to `Simulator`, then its seeded `sim.rng` selects exactly one member of the sorted eligible core set. No second RNG and no role mutation are introduced.

### Single-target overload application

`Simulator.send_message` retains existing all-cluster-head behaviour for other comparators. Only when `strategy_name == "dcsoc"` and `experiment_name == "exp08"` does it apply the configured cluster-head overload penalty solely when:

```text
destination.node_id == simulator.dcsoc_overload_target_id
```

Thus the DC-SoC repair is comparator- and experiment-scoped. Gossip, Structured, and AHBN logic is unchanged.

### Master block-source repair

For Exp08 DC-SoC only, `run_single` replaces the configured generic source with the current result of `get_dcsoc_master(nodes)` after structure construction. The selected overload target and the block source remain independent concepts. Other comparator source semantics are unchanged.
