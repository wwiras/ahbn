## Runtime Call Path

`run_one.py` / `run_batch.py` select strategy name `cluster` -> `assign_static_clusters()` assigns round-robin cluster membership, one head per cluster, and a bidirectional chain of gateway-head relationships -> `ClusterStrategy()` is constructed with `fanout=None` -> `Simulator.handle_receive()` invokes `select_targets()` -> head/member target lookup occurs in `ClusterStrategy` -> simulator deduplicates the returned list and calls `send_message()` once per target.

## Defined Structural Relationships

- Member -> own cluster head: directional upward obligation.
- Cluster head -> active members of its cluster: directional downward obligations.
- Cluster head <-> adjacent cluster heads in the gateway chain: bidirectional gateway relationships.
- Physical `Node.neighbors` are not standalone Structured forwarding relationships.

## Eligible Structural Target Rule

- Head: all active own-cluster members other than self plus all active gateway heads, deduplicated, minus the immediate sender.
- Member: active own-cluster head, unless it is the immediate sender.

## Fanout / Numeric-Cap Audit

Standalone construction in both runners is `ClusterStrategy()` and therefore `fanout=None`. In that branch `_select_head_targets()` returns all members plus gateways. The bounded code in `ClusterStrategy` is reached only when canonical `AHBNStrategy` mutates its private `_cluster.fanout`; it is AHBN-only, not the standalone Structured comparator. Gossip sampling, DC-SoC limits, AHBN controller bounds, and `HybridFixedStrategy` caps are unrelated comparator-specific paths.

Target-count selection probes reached the real `ClusterStrategy.select_targets()` implementation and passed for 1 through 7 eligible obligations. No truncation at 3 or 6 was observed.

## Sender-Exclusion Audit

Finding before repair: `ClusterStrategy` accepted `exclude_target_id`, but `Simulator.handle_receive()` passed the sender only to AHBN and Gossip. Standalone Structured therefore could immediately return a newly received message to a member or gateway sender.

Smallest repair: import `ClusterStrategy` in `ahbn/simulator.py` and add a comparator-specific dispatch branch that passes `exclude_target_id=src_id`. No target-selection algorithm changed.
